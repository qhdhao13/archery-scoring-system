# 📱 手机使用指南

## 🚀 快速开始

### 第一步：启动系统
在你的电脑上运行：
```bash
cd "Archery Target Ring Scoring System"
python run.py
```

### 第二步：获取访问地址
1. **查看电脑IP地址**
   - Windows: 运行 `ipconfig`
   - Mac/Linux: 运行 `ifconfig`
   - 找到类似 `192.168.1.100` 的地址

2. **手机访问地址**
   ```
   http://你的电脑IP:5000
   例如: http://192.168.1.100:5000
   ```

### 第三步：手机连接
- 确保手机和电脑连接同一个WiFi网络
- 在手机浏览器中输入访问地址

## 📸 拍照使用步骤

### 1. 选择靶纸类型
- 18米靶纸 (40cm直径) - 室内训练
- 30米靶纸 (80cm直径) - 标准训练
- 50米靶纸 (80cm直径) - 比赛标准
- 70米靶纸 (122cm直径) - 奥运会标准

### 2. 拍照上传
```
📱 操作步骤：
1. 点击拍照区域
2. 选择"拍照"或"从相册选择"
3. 拍摄靶纸照片
4. 点击"开始分析"
5. 等待处理完成
6. 查看得分结果
```

### 3. 查看结果
- **总得分**: 所有箭矢的总分
- **平均分**: 平均每箭得分
- **箭矢数量**: 检测到的箭矢数量
- **表现评级**: A+到F的综合评级
- **详细得分**: 每支箭的具体得分
- **标记图片**: 带有检测结果的图片

## 🎯 拍照技巧

### 拍摄要求
- ✅ **光线充足**: 避免阴影和反光
- ✅ **角度垂直**: 尽量垂直拍摄靶纸
- ✅ **靶纸完整**: 确保边缘完全可见
- ✅ **箭矢清晰**: 与背景对比明显
- ✅ **距离适中**: 不要离得太远或太近

### 推荐设置
- **分辨率**: 1920x1080或更高
- **格式**: JPG或PNG
- **对焦**: 手动对焦到靶纸中心
- **防抖**: 开启防抖功能

### 常见问题解决
```
❌ 问题: 系统无法识别靶纸
✅ 解决: 确保光线充足，靶纸边缘清晰

❌ 问题: 箭矢检测不准确
✅ 解决: 调整拍摄角度，避免反光

❌ 问题: 处理速度慢
✅ 解决: 降低图片分辨率，关闭HDR
```

## 🔢 手动输入模式

### 使用场景
- 系统无法自动识别时
- 需要精确输入坐标
- 离线计算得分

### 操作步骤
```
1. 滚动到"手动得分计算"区域
2. 选择靶纸类型
3. 点击"添加箭矢"
4. 输入X、Y坐标或距离
5. 重复添加多支箭
6. 点击"计算得分"
7. 查看计算结果
```

## 📊 批量处理

### 功能说明
- 支持同时上传多张照片
- 批量分析所有靶纸
- 生成汇总报告

### 使用方法
```
1. 点击"批量处理"区域
2. 选择多个照片文件
3. 选择靶纸类型
4. 点击"开始批量处理"
5. 等待处理完成
6. 查看批量结果
```
