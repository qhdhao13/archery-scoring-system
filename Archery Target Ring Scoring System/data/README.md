# 测试数据目录

这个目录用于存放测试用的射箭靶纸图片和示例数据。

## 目录结构
```
data/
├── README.md              # 本说明文件
├── sample_images/         # 示例图片目录
├── test_results/          # 测试结果目录
└── expected_outputs/      # 期望输出目录
```

## 测试图片要求

### 1. 图片格式
- 支持格式: JPG, PNG, JPEG
- 推荐分辨率: 1920x1080 或更高
- 文件大小: 建议小于16MB

### 2. 拍摄要求
- 光线充足，避免阴影
- 靶纸完整可见，边缘清晰
- 箭矢清晰可见，与背景对比明显
- 拍摄角度尽量垂直，避免倾斜

### 3. 靶纸类型
- 18米靶纸 (40cm直径)
- 30米靶纸 (80cm直径)
- 50米靶纸 (80cm直径)
- 70米靶纸 (122cm直径)

## 测试场景

### 1. 单箭测试
- 靶心命中 (10环)
- 不同环数命中
- 边缘命中 (1环)

### 2. 多箭测试
- 2-3支箭的组射
- 不同分布模式
- 重叠箭矢

### 3. 边界情况
- 模糊图片
- 光线不足
- 部分遮挡
- 角度倾斜

## 添加测试图片

1. 将测试图片放入 `sample_images/` 目录
2. 在文件名中标注预期结果，例如：
   - `single_arrow_10_ring.jpg` (单箭10环)
   - `three_arrows_group.jpg` (三箭组射)
   - `edge_case_blurry.jpg` (模糊边界情况)

## 运行测试

```bash
# 启动系统
python run.py

# 在浏览器中访问 http://localhost:5000
# 上传测试图片进行验证
```

## 预期结果验证

系统应该能够：
1. 正确识别靶纸边缘和中心
2. 准确检测箭矢位置
3. 计算正确的得分
4. 提供合理的性能分析
5. 生成清晰的标记结果图

## 性能基准

- 图像处理时间: < 5秒 (标准图片)
- 识别准确率: > 90% (清晰图片)
- 得分计算精度: 100% (正确识别情况下)
- 支持并发处理: 5个以上用户同时使用
