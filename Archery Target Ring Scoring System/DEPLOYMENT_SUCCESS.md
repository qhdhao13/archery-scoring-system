## 📱 使用方法

### 1. 手机拍照上传
1. 在手机浏览器中访问: `http://49.232.232.27:5000`
2. 点击"拍照上传靶纸"区域
3. 选择或拍摄靶纸照片
4. 选择靶纸类型（18m、30m、50m、70m）
5. 点击"开始识别"按钮
6. 等待系统自动识别箭矢并计算得分

### 2. 手动输入得分
1. 在"手动计算得分"区域
2. 选择靶纸类型
3. 添加箭矢位置（距离中心或坐标）
4. 点击"计算得分"按钮
5. 查看详细分析结果

### 3. 批量处理
1. 在"批量处理"区域
2. 选择多个靶纸照片
3. 选择靶纸类型
4. 点击"开始批量处理"
5. 查看所有结果

## 📝 使用建议

### 拍照技巧
1. **光线充足**: 确保靶纸清晰可见
2. **角度正确**: 尽量垂直拍摄，避免倾斜
3. **距离适中**: 不要离得太远或太近
4. **背景简单**: 避免复杂背景干扰识别

### 最佳实践
1. **定期训练**: 建议每周使用2-3次
2. **记录分析**: 保存得分数据，跟踪进步
3. **对比分析**: 对比不同时期的得分变化
4. **技术改进**: 根据分析结果调整训练方法
